# Finkit Documentation

This directory contains the user, developer, architecture, and release documentation for Finkit, a high-performance financial technical analysis library written in Rust.

The two navigation entry points are:

- This file for repository documentation and direct links.

## Generated source of truth

- [Indicator registry](indicator_registry.json) is the canonical machine-readable indicator catalog.
- `scripts/gen_ssot_docs.py` generates derived indicator documentation.
- `scripts/gen_c_header.py` generates the C FFI header.
- [Docs Check workflow](../.github/workflows/docs-check.yml) verifies all generated SSOT documents and release-version consistency before accepting changes.

## Documentation maintenance

Keep end-user installation and API instructions in the sections above. Keep implementation details in `architecture/` and `src/`. Historical planning, progress snapshots, duplicate indexes, and obsolete brand-specific documents have been removed from this tree. Update this index whenever a canonical document is added or moved.
