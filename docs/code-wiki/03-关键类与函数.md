# 03 · 关键类与函数

本文列出跨模块复用、调用约定最"承重"的关键 trait / struct / 函数，帮助快速定位 API 与扩展点。路径均相对仓库根。

## 1. 顶层公共 trait（`core/src/traits.rs` / `streaming/traits.rs`）

### `Ohlcv`（OHLCV 数据访问）
```rust
pub trait Ohlcv {
    fn open(&self) -> f64;   fn high(&self) -> f64;
    fn low(&self) -> f64;    fn close(&self) -> f64;
    fn volume(&self) -> f64;
    // 默认实现提供：
    fn typical_price(&self) -> f64;  // (H+L+C)/3
    fn median_price(&self) -> f64;   // (H+L)/2
    fn weighted_close(&self) -> f64; // (H+L+2C)/4
    fn true_range(&self, prev_close: f64) -> f64;
    fn open_time(&self) -> i64;      // 生成中 bar 防重绘用，默认 0=关闭
}
```
> 局部实现见 [core/src/streaming/traits.rs](../../core/src/streaming/traits.rs)。`OhlcvBar` 是其具体化结构体；`OhlcvArrayAdapter` 让 `f64` 切片 / ndarray 数组也满足该 trait。

### `StreamingIndicator<Input=f64, Output=f64>`（流式指标，O(1)/bar）
```rust
pub trait StreamingIndicator<Input = f64, Output = f64> {
    fn next(&mut self, input: Input) -> Option<Output>; // None=预热期
    fn next_with_time(&mut self, input: Input, _open_time: i64) -> Option<Output>; // 支持生成中bar回滚
    fn reset(&mut self);
    fn is_ready(&self) -> bool;
    fn count(&self) -> usize;
    fn value(&self) -> Option<Output>; // 缓存的上次值，不改状态
}
```

### `IndicatorMeta`（注册表元数据）
```rust
pub trait IndicatorMeta {

    fn description() -> &'static str;
    fn warm_up_period(&self) -> usize;
}
```

### `BatchIndicator`
批量指标统一接口（输入 `&[f64]` → `Result<Array1<f64>>`），见 `core/src/traits.rs`。

## 2. 批量指标层（`core/src/indicators/`）

- 入口 re-export 全部函数到 `crate::indicators::*`（例如 `indicators::sma(&close, 3)`）。
- **零分配输出 trait**：
```rust
pub trait SliceOutput {
    fn compute_into(&self, input: &[f64], output: &mut [f64]) -> Result<()>;
}
```
- 具体适配器：`SmaSlice(pub usize)`、`EmaSlice(pub usize)`，以及宏 `impl_slice_output!` 生成的 `RsiSlice/CmoSlice/TrixSlice/ApoSlice/PpoSlice/RocpSlice/RocrSlice/Rocr100Slice/TrimaSlice/MomSlice/RocSlice`。
- **越界热路径宏**：`idx!(slice, i)` / `idx_mut!(slice, i)`——开启 `unchecked-indexing` feature 时用 `get_unchecked` 跳边界检查。
- 便捷函数：`sma_into_slice` / `ema_into_slice`（写调用方 buffer）。

## 3. 流式层（`core/src/streaming/`）

- **注册表**（`registry.rs`）：
  - `IndicatorInfo { name, category, description, params, convergence, streaming }`
  - `ParamInfo { name, param_type, default, description }`
  - `RegistryDocument { version, generated_at, indicators }`
  - `VALID_CATEGORIES: &[&str]`（overlap/momentum/volume/volatility/price_transform/cycle/statistics/breadth/sentiment/math_transform/math_operators/fibonacci/pattern/astock）
  - 通过 `OnceLock` 缓存 `INDICATOR_CACHE` / `INDICATOR_BY_ID` / `INDICATOR_BY_CATEGORY`，O(1) 按名/分类查询。
- **builder**：`IndicatorBuilder` + `Builder`，如 `StreamingSma::builder().period(14).build()`。
- **checkpoint / repaint**：`checkpoint.rs`（serde 状态保存/恢复）、`repaint.rs`（生成中 bar 重绘）。
- **数据结构**：`ring_buffer.rs`、`rolling_minmax.rs`（单调双端队列，SWEEP/AROON/WILLR 等热路径加速）。
- 每种指标一个 struct：`StreamingSma`、`StreamingRsi`、`StreamingMacd`、`StreamingBoll`、`StreamingStoch` 等（98 个），见 `core/src/streaming/{overlap,momentum,volume,volatility,trend,...}/`。

## 4. 公式引擎（`core/src/formula/`）

核心入口 `FormulaEngine`（engine.rs）：
```rust
pub struct FormulaEngine { executor, cache, templates, jit_compiler }
impl FormulaEngine {
    pub fn new() -> Self;
    pub fn with_cache_size(n: usize) -> Self;
    pub fn compile(&mut self, src: &str) -> Result<CompiledFormula, FormulaError>;
    pub fn execute(&self, f: &CompiledFormula, ctx: &mut FormulaContext) -> Result<Array1<f64>, FormulaError>;
    pub fn eval(&mut self, src: &str, ctx: &mut FormulaContext) -> Result<Array1<f64>, FormulaError>; // 编译+执行
}
```
**内部流水线（编译 → 执行）：**

| 阶段 | 文件 | 说明 |
|------|------|------|
| 解析 | `parser.rs` + `grammar.pest` | pest 文法，支持方言（TDX/THS/DZH/Pine） |
| AST | `ast.rs` | 语法树节点 `AstNode` |
| 编译缓存 | `compiler.rs` | `CompiledFormula` + `FormulaCache`（真 LRU，O(1)）；缓存命中可加速 ~23x |
| 字节码 | `bytecode.rs` | `compile_to_bytecode`、`Bytecode`、`BytecodeVM` |
| 执行 | `executor.rs` | 解释执行 |
| JIT | `jit.rs` | `JitCompiler`、`OptimizedBytecode` |
| 优化 | `optimizer.rs` | `FormulaOptimizer`、`DependencyAnalyzer` |
| SIMD | `simd.rs` | 指令级加速（add/mul/sma 等 5–37x） |
| 模板 | `templates.rs` | `FormulaTemplates`，309 个经典指标模板 |
| 调试 | `debugger.rs` | `FormulaDebugger`，逐步追踪 |
| 参数 | `params.rs` | `ParamDef`/`ParamValues`，apply/parse/validate |
| 沙箱 | `sandbox.rs` | 安全的公式执行环境 |
| 内存池 | `memory_pool.rs` | 指令执行期缓冲复用 |

**方言与兼容**：`pine/`（Pine Script v5 解析器，`grammar.pest` + `ast_mapper.rs` + `builtin_table.rs` + `runtime.rs`）。兼容目标：TDX 100%、THS 96.3%、DZH 100%、文华 90%、Pine ~60%。

## 8. FFI 层关键约定

- **C ABI 命名**：统一 `ta_*` 前缀（如 `ta_sma`、`ta_macd`）；**配对释放** `ta_free_result` / `ta_free_cstring`，避免跨语言内存泄漏（见 [ffi/](../ffi/) 与 [FFI_MEMORY_CONTRACT.md](../FFI_MEMORY_CONTRACT.md)）。
- **golden 对齐**：`ffi-common/golden.rs` 提供各语言测试共用的黄金向量，确保 8 个绑定输出与 core 一致。
- **panic 安全**：跨 FFI 边界用 `catch_unwind` 转成错误码/异常，防止 unwind 到 C ABI（`ffi-common/panic.rs`）。
- **生成代码**：各绑定 `src/generated.rs` 由 `scripts/sync_bindings.py` 从 `docs/indicator_registry.json` 生成；`lib.rs` 负责手工封装（如 NumPy 零拷贝、await 异步）。
