# 02 · 核心模块职责

本文按模块边界说明 finkit（AlphaTA）各部分的职责。核心全部位于 `core/src/`，绑定层位于 `ffi/`，其余为 CLI/可视化/WASM。

## 1. `alpha-ta-core` 模块总览

模块入口见 [core/src/lib.rs](../../core/src/lib.rs)。各模块大多通过 feature flag 开关，默认 `std + formula + indicators-all` 全量开启。

| 模块 | 路径 | 职责 |
|------|------|------|
| `error` | `src/error.rs` | 领域错误类型：`TaError`、`IndicatorError`、`FormulaError`、`Result` 别名 |
| `traits` | `src/traits.rs` | 跨领域顶层 trait：`Ohlcv`、`OhlcvBar`、`OhlcvArrayAdapter`、`BatchIndicator`、`StreamingIndicator` |
| `indicators` | `src/indicators/` | 150+ **批量**指标（输入 `&[f64]`，输出 `Array1<f64>`），按分类拆分：overlap/momentum/volume/volatility/cycle/statistics/price_transform/pattern/market(astock/china/sentiment/breadth...) |
| `streaming` | `src/streaming/` | 98 个 **流式 O(1)** 指标 + builder/registry/checkpoint/ring_buffer/repaint。目录结构与 indicators 分类一致（overlap/momentum/volume/volatility/trend/statistics/breadth/...） |
| `math` | `src/math/` | 数学基元：`moving_avg`（SMA/EMA/WMA/DEMA/TEMA/KAMA/TRIMA）、`linear`（回归）、`statistics`、SIMD 内核（`simd_kernels`/`simd_ops`/`simd_ops_avx512`/`simd_ops_wasm`）、`buffer_pool`（热路径缓冲池）、`libm_shim`（no_std 的 libm 垫片） |
| `formula` | `src/formula/` | 公式引擎：`parser`（pest 文法）→ `ast` → `bytecode`（编译）→ `executor`（解释执行）→ `jit`（JIT 优化）→ `simd`；含 `optimizer`、`debugger`、`templates`（309 个模板）、`memory_pool`、`sandbox`、`pine`（Pine Script v5 兼容） |
| `patterns` | `src/patterns/` | 60+ K 线形态（candlestick）+ 15+ 图表形态（chart）+ 经典形态扩展（classic_ext）+ harmonic |
| `features` | `src/features/` | ML 特征工程：`engine`、`normalization`、`pca`、`wavelet`、`fourier`、`garch`、`regime`、`meta_labels`、`labels`、`importance`、`selection`、`cross_features`、`transforms`、`timeseries`、`encoding` |
| `transforms` | `src/transforms/` | 数据变换流水线：`pipeline`（LogReturn/ZScore/MinMaxScaler）、`rolling`、`diff`、`pct_change`、`rank`、`scaler` |
| `backtest` | `src/backtest.rs` | 轻量向量化回测引擎 |
| `buses/selectors` | `src/selectors.rs` | 选股因子合成 + 横截面排序 |
| `risk` | `src/risk.rs` | 组合风险指标：VaR / CVaR / MDD / Sharpe / Sortino / Calmar |
| `sector` | `src/sector.rs` | 申万一级 31 行业板块轮动 |
| `multi_period_resonance` | `src/multi_period_resonance.rs` | 多周期共振信号（5m/30m/日线 联动） |
| `batch` | `src/batch.rs` | rayon 并行批量 API（`parallel_sma_batch` 等），`rayon` feature |
| `polars_ext` | `src/polars_ext/` | Polars DataFrame 零拷贝集成（`alpha-ta-polars` feature） |
| `talib_ffi` | `src/talib_ffi.rs` | TA-Lib C 库 FFI 兼容层（`talib-c` feature） |
| `metrics` | `src/metrics.rs` | 观测指标门面（`metrics` crate 封装，Prometheus exporter 可选） |
| `utils` | `src/utils.rs` | 输入校验、平滑因子、数组工具 |

## 2. `alpha-ta-visualization` 模块

纯 Rust 的 K 线渲染，无需浏览器/外部依赖，位于 `visualization/src/`。

| 模块 | 职责 |
|------|------|
| `chart/mod.rs` | 图表装配入口；`candlestick.rs`/`line_chart.rs`/`area_chart.rs`/`ohlc_bar.rs` 四种图表 |
| `chart/indicators.rs` | 叠加指标（MA/EMA/BOLL/MACD/RSI/KDJ/SAR） |
| `config.rs` | `ChartConfigBuilder`（尺寸、主题、语言、图表类型） |
| `data.rs` | `KlineData` 数据模型 |
| `render/mod.rs` | `svg.rs`/`png.rs`/`html.rs`/`json.rs` 四种输出后端 |
| `interaction/` | `crosshair.rs`（十字光标）/`zoom.rs`/`pan.rs` 交互 |
| `decimate.rs` | LTTB/MinMax/EveryNth 降采样（百万级流畅渲染） |
| `language.rs` | 中/英双语与涨跌配色 |

## 3. `alpha-ta-cli`

见 [cli/src/main.rs](../../cli/src/main.rs)，14 个子命令：`sma ema wma rsi macd bbands atr stoch adx cci obv willr pattern formula`，支持 CSV/JSON 输出与 stdin 管道。

## 4. `ffi/` 各绑定层职责

| 绑定 | 技术 | 关键职责 |
|------|------|---------|
| `c-binding` | cbindgen | 导出 `ta_*` C ABI（`ta_sma` 等），生成 `include/alpha_ta.h` 与 C++ 封装 `.hpp`；提供 `ta_free_result` 配对释放 |
| `python-binding` | PyO3 + maturin | 20+ 函数、NumPy 零拷贝、GIL 释放；`alpha_ta/` 包（`__init__.py`/`accessor.py`/`exceptions.py`） |
| `node-binding` | napi-rs | 同步+异步计算、TypeScript 类型（`index.d.ts`）、跨平台 prebuild npm 目录结构 |
| `go-binding` | cgo | C ABI shim + Go 包（`go/ta/ta.go`、`result_types.go`） |
| `java-binding` | JNI | 20+ 函数、结构化返回（`MacdResult/BbandsResult/StochResult`）、panic 保护（catch_unwind） |
| `android-binding` | JNI + CMake | Android `.so`、gradle 构建 |
| `ios-binding` | Swift + xcframework | `build-xcframework.sh` 生成 AlphaTA 框架 |
| `dotnet-binding` | P/Invoke | NuGet 打包、`ta_free_cstring` 配对释放 |
| `ffi-common` | Rust | 全绑定共享：`error/panic/leak/golden/registry/types` |

> 备注：本项目通过 `docs/indicator_registry.json`（单一事实源）驱动 C 头文件生成（`scripts/gen_c_header.py`）与 8 个绑定的 `generated.rs`（`scripts/sync_bindings.py`），并用 `cargo test` + `verify-all-bindings` 防止"漂移"。

## 5. `wasm/` 模块

`wasm/src/` 暴露 `lib.rs`（核心指标）、`streaming.rs`、`transforms.rs`，供浏览器/Node 通过 wasm-bindgen 调用；另有与 core 对齐的 Streaming* wrapper。

## 6. 模块依赖的常见约定

- **分类即 feature**：`indicators-*` 与 `streaming` 模块一一对应，默认 `indicators-all` 全开；关闭某分类可裁剪二进制（见 core/Cargo.toml 注释）。
- **热路径零分配**：批量指标在 `indicators` 模块以 `SliceOutput` 写入调用方 buffer；streaming 用 `ring_buffer`/`rolling_minmax` 维持 O(1)。
- **正确性护栏**：`tests/golden/` 黄金向量、`tests/*_compat_tests.rs`（TDX/THS/DZH）、`proptest`、`fuzz/`。
