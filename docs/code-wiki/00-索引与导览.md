## 仓库性质速览

- **项目名**：finkit（仓库工作区），软件对外名 **AlphaTA**（`alpha-ta-core` 等 crate）。
- **定位**：用 Rust 编写的高性能金融技术分析库，支持 8+ 语言绑定（Python/Node/Go/Java/.NET/C/C++/WASM）与多平台（Linux/macOS/Windows/Android/iOS）。
- **规模**：177+ 批量指标、98 个流式指标、60+ K 线形态、15+ 图表形态、公式引擎（TDX/THS/DZH/Pine 兼容）、ML 特征工程。
- **性能卖点**：核心指标比 TA-Lib C 快 1.2x–3.2x（真实 FFI 基准）。
