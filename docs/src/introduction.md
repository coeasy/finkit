# Introduction

Finkit is a high-performance financial technical analysis library written in Rust. It provides 150+ batch indicators, 98 streaming indicators, candlestick and chart pattern recognition, and a formula engine with JIT and SIMD acceleration — all exposed through Python, Node.js, Java, Go, .NET, C, WebAssembly, and native Rust APIs.

This documentation covers installation, usage guides, API references, benchmarks, migration paths, and FFI bindings.
