# Finkit v0.1.0 Roadmap

## Release Goal

Create the first stable foundation version of Finkit.

## Milestone 1 Core

- Project structure
- Build system
- Core data structures
- Calculation runtime

## Milestone 2 Indicators

Initial indicator modules:

Trend:

- SMA
- EMA
- WMA
- MACD

Momentum:

- RSI
- ROC
- MOM

Volatility:

- ATR
- STD
- Bollinger Bands

Volume:

- OBV
- VWAP

## Milestone 3 Python SDK

Package:

```
pip install finkit
```

Support:

- numpy
- pandas

## Milestone 4 Testing

Requirements:

- Unit tests
- Numerical validation
- Performance benchmark

## Milestone 5 Documentation

Provide:

- API reference
- Examples
- Developer guide

## v0.1.0 Acceptance Criteria

- Installable package
- Stable API
- Core indicators available
- CI passing
- Documentation complete
