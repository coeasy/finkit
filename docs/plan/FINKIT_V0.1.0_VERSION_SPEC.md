# Finkit v0.1.0 Version Specification

## Version Policy

All project components use unified version:

```
v0.1.0
```

Including:

- Core Engine
- Python Package
- Documentation
- CLI
- SDK bindings

## Package Naming

Python:

```
finkit==0.1.0
```

Future bindings:

- finkit-rust 0.1.0
- finkit-go 0.1.0
- finkit-java 0.1.0

## Semantic Versioning

MAJOR.MINOR.PATCH

Example:

```
0.1.0
 |
 |
 initial foundation release
```

## Release Rules

- No mixed version numbers
- All examples follow current release
- Documentation follows package version
- Breaking changes require major version update
