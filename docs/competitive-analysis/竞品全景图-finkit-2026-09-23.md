## 1. 项目定位分析

| 维度 | 特点 |
|------|------|
| 核心价值主张 | **Quant Compute Runtime**：一个 Rust 核心、一套 canonical kernel、一套执行计划、一套正确性语义，多语言交付。不是"指标函数集合"，而是研究 Notebook、行情服务、因子平台、实时看板共享的计算底座 |
| 目标用户 | 量化研究平台、行情/选股服务、实时分析系统、因子与 ML 流水线、多语言金融 SDK 开发者 |
| 核心功能 | 150+ 技术指标（批量+流式 O(1)/bar）、公式引擎（通达信/同花顺/东财/Pine 方言）、因子 DAG、特征工程（31 模块）、统一运行时（DirtyRange 局部重算）、9 语言绑定、CLI/WASM |
| 技术架构 | Rust workspace（14 crates）；math 层 no_std + SIMD（AVX512/AVX2）；Numeric Architecture v3（KernelId 数字槽热循环）；pest→AST→bytecode VM/HotPlan 双路径 |
| 商业模式 | 开源（MIT OR Apache-2.0），无商业化 |
| 差异化优势 | 公式/因子计划复用、DirtyRange 局部重算、caller-owned `_into`、多语言同一语义核心、正确性门禁（多路径数值一致 + 绝对性质断言） |
| 明确边界 | 不做回测、选股引擎、OMS、交易网关、撮合 |

## 4. 竞品分析总结

### 4.1 本项目的优势

1. **架构代差**：pest→AST→HotPlan（KernelId 数字槽）→UnifiedExecutor 的编译管线，配合 FormulaCache/PlanCache 计划复用，是所有竞品都没有的"Quant Compute Runtime"形态——通达信/Pine 是解释型引擎，TA-Lib/Pandas TA 是函数集合。
2. **DirtyRange 局部重算**：唯一对"历史数据修订"建模的引擎（streaming 解决新 bar，DirtyRange 解决历史修订），且有严格的 incremental + fixed lookback + time-series safe 证明门禁。
3. **多语言同一语义核心**：9 绑定 + ffi-common SSOT + binding-ssot CI 门禁（无逃生舱），竞品中仅 TA-Lib 有类似工程化程度。
4. **正确性工程**：多路径数值一致门禁（tree/bytecode/plan 容差 1e-10 + 绝对有限值个数断言）、warm-up NaN 不污染下游、streaming vs batch 收敛 1e-12、purged CV 防泄漏——正确性作为产品能力而非文档承诺。
5. **no_std + WASM**：math 层 no_std 使嵌入式/边缘场景成为可能，竞品均无。

### 4.2 本项目的劣势

1. **指标数量被反超**：TA-Lib 0.8.1 达 200+，Pandas TA Classic 达 284，finkit 150+ 不再是第一梯队。
2. **TA-Lib 正快速补齐差异化**：0.8.1 的 Streaming API + 官方 Rust/Java/C# 原生实现 + 性能大改（MACD 8x），finkit "流式 + Rust 原生"两张牌正在贬值。
3. **公式方言覆盖未量化**：通达信数百函数（含 L2/DYNAINFO 族）与 Pine v6（UDT/matrix/map/library）的覆盖率没有兼容性测试集度量，"支持方言"停留在子集。
4. **因子研究是候选状态**：factor-analysis 未进正式版，IC/分位/换手之外，因子衰减、行业分组、事件研究、tearsheet 图表矩阵均落后 alphalens。
5. **风险指标广度不足**：对比 empyrical/quantstats 缺 alpha/beta、omega、tail_ratio、capture ratios、PSR、ulcer、kelly 等。
6. **零 registry 发布**：PyPI/npm/Maven/NuGet/go get 全部未发布，Python 仅 GitHub Release wheel，获客链路断裂。
7. **生态冷启动**：无社区脚本库、无教程内容、无学术引用，对比 Pine 10 万脚本、TA-Lib 行业标准地位。

### 4.3 最大威胁

**TA-Lib 0.8.x 的代际更新**（2026-09）：Streaming API 落地 + 200+ 指标 + 官方 Rust 原生 + 性能大幅提升，直接命中 finkit 的三个核心卖点。若 finkit 不能在**公式引擎、因子 DAG、DirtyRange、多语言 SSOT** 这些 TA-Lib 结构上不具备的能力上建立可证明优势并完成 registry 发布，窗口期将收窄。

### 4.4 市场空白机会

1. **ta crate 停更真空**：纯 Rust TA 库 2021 年后无维护（年下载仍 7.5 万），finkit 可承接迁移用户（crates.io 发布是前提）。
2. **通达信/Pine 脚本迁移杠杆**：国内存量通达信公式 + 全球 Pine 脚本，"零成本迁移 + 比原引擎快"是最强获客叙事。
3. **非 Python 生态的因子研究**：alphalens/pyfolio/quantstats 全部 Python-only，Node/Go/Java/.NET 的因子研究市场完全空白。
4. **Rust+Polars/Arrow 互操作**：Polars 月下载 3000 万+，TA-Lib wrapper 刚原生支持 Polars，finkit 的 polars_ext 零拷贝集成可抢占。
