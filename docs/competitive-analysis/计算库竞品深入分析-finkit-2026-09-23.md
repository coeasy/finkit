# 计算库竞品深入分析：TA-Lib / VectorBT / Pandas TA Classic / ta / Polars 生态

> 生成日期：2026-09-23 · 调研方式：官方文档 + GitHub + PyPI/crates.io 网络调研（未克隆仓库）
> 对照对象：finkit v0.1.15（Rust workspace，150+ 指标，公式/因子/流式/统一运行时）

---

## 1. TA-Lib（最重要对手，代际更新中）

### 1.1 现状
- **版本**：C 核 0.8.1（2026-09-12），0.8.2 开发中；Python wrapper 0.8.1（2026-09-21）
- **指标**：官网口径 200+；0.8.1 一次性新增 40+（SUPERTREND、HMA、ZLEMA、KDJ、VWAP、DONCHIAN、VORTEX、ERI 等）及新 MAType（HMA/ZLEMA/RMA/DISABLED）
- **Streaming API**：0.8.1 正式落地（ta-lib.org/api/stream/），补齐增量计算短板
- **性能**：MACD ~8x、DEMA/TEMA/TRIX 3–7x、ATR 2–4x、RSI ~2x（FMA 浮点重排）
- **绑定**：官方原生 C/C++、Java、C#、**Rust**（RUST_CONVERSION_PLAN.md 在库内推进）
- **社区**：ta-lib-python ~9.9k stars；C 库 ~1.4k；行业标准地位

### 1.2 与 finkit 逐项对比

| 维度 | TA-Lib 0.8.1 | finkit v0.1.15 | 判定 |
|------|--------------|----------------|------|
| 指标数量 | 200+ | 150+ | **finkit 落后** |
| Streaming | 0.8.1 新增 | O(1)/bar + repaint 控制 + checkpoint | finkit 仍领先（repaint/持久化） |
| Rust 原生 | 官方推进中 | ✅ 本体 | 追平中 |
| 公式引擎 | ❌ | ✅ 320 函数 + 4 方言 | **finkit 独有** |
| 因子 DAG | ❌ | ✅ | **finkit 独有** |
| DirtyRange | ❌ | ✅ 安全链 | **finkit 独有** |
| 计划复用 | ❌ | FormulaCache/PlanCache | **finkit 独有** |
| registry 发布 | ✅ PyPI | ❌ | **finkit 落后** |

### 1.3 值得借鉴的设计亮点
1. **版本节奏与 CHANGELOG 工程**：0.7→0.8 一年内完成 Streaming + 40 指标 + 性能大改，每项绑定 issue 与基准数据——finkit 的 CHANGELOG 应学习其"每个性能声明附可复现数字"。
2. **MAType 可扩展枚举**：新增 HMA/ZLEMA/RMA/DISABLED 作为通用均线类型注入所有依赖均线的指标——finkit 已有 `MaType` 分发，但应核对是否覆盖同等扩展性。
3. **Streaming API 的 C ABI 设计**：状态句柄 + 逐 bar 推进，与 finkit streaming 同构，但其官方文档直接给出各语言示例——finkit 的 streaming 文档化程度不足。
4. **Rust 转换计划公开化**（RUST_CONVERSION_PLAN.md）：把语言移植当作公开路线图管理。
5. **Python wrapper 原生支持 Pandas/Polars 双后端**：finkit 的 polars_ext 仅 8 个方法，差距明显。

## 2. VectorBT

### 2.1 现状
- 开源版 1.1.0（2026-07-05），~9.1k stars；PRO 为闭源商业版
- Numba JIT 向量化回测、参数扫描广播矩阵、**可选 Rust 引擎**（`pip install vectorbt[rust]`，预编译免 JIT 冷启动）、walk-forward
- 协议 Apache 2.0 + Commons Clause（非纯开源）

### 2.2 与 finkit 关系
定位不同：VectorBT 是回测+研究产品（finkit 明确不做回测），但其**把 Rust 内核当卖点**验证了市场认知。finkit 可作为 VectorBT 类产品的底层引擎（其 TA 集成目前走 TA-Lib/Pandas TA）。

### 2.3 值得借鉴
1. **参数扫描（sweep）的 API 形态**：广播矩阵一次算 N 参数组合——finkit CLI 已有 sweep 子命令，但库层 API 未暴露同等能力。
2. **免 JIT 冷启动叙事**：Rust 预编译 vs Numba 首次编译等待，finkit 的 Python 绑定可直接对标宣传。
3. **PRO/开源分层商业模式**：finkit 未来若商业化可参考。

## 3. Pandas TA Classic

### 3.1 现状
- 0.8.32（2026-09-14）；一年内 0.3→0.8 高频迭代，是停更的 pandas-ta（0.4.71b0，2025-09）的事实继任者
- **284 个**（224 指标 + 62 K 线形态），无需 TA-Lib 依赖；Python 3.10–3.14；Numba/Numpy 加速路径

### 3.2 与 finkit 对比
指标数量 284 vs 150+，**finkit 数量劣势明确**。但 finkit 的 320 个公式函数（含通达信族）与 150+ 指标有部分重叠口径，对外宣传口径需统一（见差距分析）。

### 3.3 值得借鉴
1. **DataFrame accessor 体验**（`df.ta`）：一行启用、动态指标发现——finkit polars_ext 应达到同等易用性。
2. **发布节奏**：一年 5 个大版本，每次附 changelog 与指标增量清单。
3. **"无需 TA-Lib 依赖"的独立安装叙事**。

## 4. ta (Rust crate) 与 Rust 生态

- **ta**：0.5.0（2021-06）后停更；累计下载 35 万、年下载仍 7.5 万——**纯 Rust TA 库供给真空**，finkit 上 crates.io 可直接承接。
- **barter-rs** 0.14.0（2026-08）活跃：事件驱动交易框架，9.2 万下载——潜在下游集成方。
- **kand**：Rust+Python+WASM TA 库，2026-01 加 WASM，活跃——与 finkit 定位最接近的 Rust 新兴竞品。
- **nautilus_trader / AKQuant**：Rust 原生交易引擎 / Rust+Python 因子表达式引擎（talib 双后端 103 指标 + Polars）——证明"Rust 因子引擎"赛道已有玩家。

### 启示
finkit 在 Rust 生态的真正对手不是 ta（已死）而是 **kand/AKQuant**；差异化在公式引擎 + 因子 DAG + DirtyRange，而非指标数量。

---

## 5. Polars / NumPy 生态影响

- Polars 39.7k stars、月下载 3000 万+；TA-Lib Python wrapper 已原生接受 Polars Series（千万行 SMA 比 Pandas 快 ~3x）
- NumPy 2.x：NEP 38 通用 intrinsics + 运行时 CPU 分派，ufunc 覆盖 AVX-512；`sliding_window_view` 零拷贝滑窗使简单指标纯 NumPy 即可高效实现
- **影响判断**：简单指标（SMA 类）的门槛已降到"NumPy 一行"，TA 库的价值必须向**状态化/流式/复杂语义/公式/因子**迁移——这正是 finkit 的架构方向，但 polars_ext 现状（4+4 方法、提取 Vec<f64> 计算、无 expressions/plugin）远不足以承接。

---

## 6. 对 finkit 的核心结论

1. **数量牌已失效**：TA-Lib 200+、Pandas TA 284、finkit 150+（宣传口径混乱：公式函数 320 vs 指标 150+）。应统一口径并补齐 TA-Lib 0.8.1 新增的 40+ 指标（多数 finkit 已有等价实现，如 SUPERTREND/DONCHIAN/VORTEX 在 streaming/ 中存在，需对齐命名与契约）。
2. **差异化必须显性化**：公式引擎/因子 DAG/DirtyRange/计划复用是 TA-Lib 结构上没有的，但当前文档与 API 参考没有把它们讲清楚（api-reference.md 仅 17 个签名）。
3. **polars_ext 是最薄弱环节**：竞品已把 Polars 支持当标配，finkit 仅 8 个方法。
4. **registry 发布是获客前提**：ta crate 停更真空 + kand 活跃，crates.io/PyPI 窗口期有限。
