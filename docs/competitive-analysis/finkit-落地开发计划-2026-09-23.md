| `docs/generated/formula-functions.md` | **待做**：`python scripts/gen_ssot_docs.py --generate` 重生成 |

**做法要点（已按 TRAPS 红线设计）**

1. 每个 wrapper 走 `warmup_offset()` + `shift_back()`（`start==0` 时逐位等同直接调用 → golden/benchmark 不动），避免"滚动核被上游预热段毒死"的同型缺陷。
2. **不重写任何算法**，一律委托 golden 对照的那一个库函数，避免制造 tree/plan 分叉。
3. 多输出函数沿用既有 `BOLL/BOLLMID/BOLLDN` 约定：主名给主输出，每个输出另给 `<NAME>_<OUTPUT>` 后缀名
   （`ACCBANDS_MID/LOWER`、`AROON_DOWN`、`ERI_BULL/BEAR`、`FRACTAL_HIGH/LOW`、`HA_OPEN/HIGH/LOW/CLOSE`、`KC_MID/LOWER`、`MAMA_FAMA`、`SMI_SIGNAL`、`VORTEX_PLUS/MINUS`）。
4. 参数顺序 = golden `inputs` 在前、`parameters` 在后，缺省值取 golden 的 `parameters`。

**验收**

- [ ] `ZLEMA(CLOSE,20)` 等 31 个名字在 `get_builtin_functions()` 中全部命中
- [ ] 31 个函数对 golden 逐值一致（默认容差 1e-10；个别族按 `golden_talib_tests.rs` 既有政策放宽并写原因）

**风险**：`COPPOCK` 的 roc 长短参数顺序、`AC` 的信号线定义可能与 golden 有差异 → 先跑 parity，按实测调整参数映射，绝不改库函数。

## 4. 需要你拍板的三个决策

**决策 1 — PyPI 包名（阻塞 M0-4）**
`finkit` 在 PyPI 已被 `FinKit 0.0.0` 空包占用。选项：
- (a) `finkit-quant` / `finkit-core` 等替代名 —— 立即可发
- (b) 申请 PEP 541 名称转移（空包、单版本，成功率较高，但需数周且不保证）
- (c) 先只发 crates.io，PyPI 走 GitHub Release 现状

**决策 2 — 31 个函数的多输出命名**
方案只说"注册 31 个"。我按既有 `BOLL/BOLLMID/BOLLDN` 约定给每个输出都加了后缀名（共 48 个注册项）。若你希望严格只加 31 个名字、其余输出不暴露，告诉我，我改。

**决策 3 — M0-1 的容差**
方案写 1e-10，但 `golden_talib_tests.rs` 既有政策对 SMA/WMA/BBANDS/AD 等族用 1e-6、EMA 族用 1e-8。我倾向沿用既有分族政策（并在新测试里写清原因），而不是给新函数开一个更松或更紧的特例。
