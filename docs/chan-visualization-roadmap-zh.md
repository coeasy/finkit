# 缠论与绘图完善方案

本文是 Finkit 缠论和绘图模块的演进基线。实现参考了 CZSC 的分层数据模型，以及 stockstats 的“参数显式、按需计算、结果可组合”使用方式；不直接复制 Python 端对象或绘图库依赖。

## 当前基线

第一轮已完成：

- `finkit::chan`：原始 K 线 → 去包含 K 线 → 分型 → 笔 → 三笔段 → 中枢；
- `ChanConfig::min_stroke_bars`：默认 6，允许针对不同缠论流派或小样本数据调整；
- `ChanAnalyzer`：支持 `append` 延迟结构计算、`push` 单根即时快照、`extend` 批量回放和缓存快照；实时接入可以先批量写入，再按刷新节奏计算结构，避免每根行情都重建全量结果；
- 结构结果增加力度、斜率、长度、趋势、未确认分型以及 B1/B2/B3、S1/S2/S3 候选；
- 增加严格/宽松分型、5/6/7 根笔、阈值笔、动态/层级中枢等可配置变种；
- `finkit-visualization`：主图叠加分型标记、笔、线段和半透明中枢带，默认关闭；
- 图层增加未确认结构和买卖点候选的可见性控制；
- 增加按因子自动聚合的多周期缠论分析，并将结构索引映射回基础周期；支持真实时间戳、自动秒级层次、会话起点对齐和源区间回溯；`TradingCalendar` 进一步支持 A 股、国内期货、港股、美股、加密货币 preset、常用时区与美股 DST、周末、节假日、午间休市、半日市和跨午夜 session 过滤；
- `finkit::composite` 与 Python `compute_composite`、Node `computeComposite`：声明式依赖图、共享缓存和环检测；
- Python/Node/WASM：均可开启单周期/多周期缠论叠加、阈值配置、回放和批量实时更新；Canvas 浮窗也复用指标与结构命中信息。
- `KlineData` 可选携带严格递增的 Unix 秒级时间戳；JSON、HTML 和 Canvas 数据窗统一传递时间戳，Rust/Python/Node/WASM 的时间戳实时 upsert 不会退化成 date-only 时间轴。

默认实现采用严格三 K 线分型和交替分型，旨在保证确定性与可解释性。线段采用三笔保守构造；中枢支持三笔固定、动态延伸和递归层级合并。它仍是可解释的规则基线，不宣称覆盖所有缠论流派的唯一裁定。

## 分阶段路线

### P0：语义稳定与回归保护

1. 固化 OHLCV 数据校验、去包含边界、平台/平底等相等价位规则。
2. 引入来自真实 A 股、期货和数字资产的脱敏 fixture，与 CZSC 结果做结构级对照：分型索引、笔端点、中枢上下沿分别比较。
3. 把“已确认结构”和“当前未完成结构”分开输出，避免把最后一根 K 线的临时形态误当成已确认信号。
4. 明确前复权、停牌、缺口、跨交易日和异常 K 线的输入契约。

### P1：缠论核心完善（主体已落地，持续校准）

1. 增加可插拔 `FractalPolicy`、`StrokePolicy` 和 `CenterPolicy`，兼容至少两种常用笔定义（最小 K 线数、分型间隔、严格/宽松确认）。
2. 增加线段、走势趋势、背驰候选和一/二/三类买卖点的“结构描述” API；信号带 `evidence` 原始索引，背驰候选独立于可执行策略信号，仍需用真实 fixture 继续校准。
3. 增加多周期 `BarAggregator`，已完成因子聚合、真实时间戳、自动秒级层次、会话起点对齐、交易日历过滤和源区间回溯。交易所年度假日表仍通过用户配置或行情适配器注入。
4. `ChanAnalyzer` 已提供确定性的流式快照 API：`append` 只做校验和写入，`snapshot_cached` 按需刷新，`extend` 一次分析批量数据，`push` 保留易用的单根即时模式。当前结构快照仍以确定性批处理为准；如需极低延迟，可在不改变批量结果模型的前提下继续增加局部尾部识别。

### P1：绘图质量与交互

1. 增加主图/副图图层模型，给每个结构层提供可见性、颜色、线宽、标签和 z-order。
2. 补充日期轴、缩放/平移后的结构索引映射，以及只绘制可视窗口的路径裁剪。
3. HTML 输出增加结构悬停信息：分型类型、笔方向/涨跌幅/长度、中枢上下沿/持续笔数。
4. 增加统一 JSON schema，让 Python、WASM、Node 和前端可以复用同一份结构数据；HTML 与 Canvas 浮窗共享指标及命中对象。

本轮性能与可读性优化已完成一批基础能力：

- 主图和成交量按画布宽度进行自适应抽样；K 线默认使用 MinMax 保留高低点，折线默认使用 LTTB 保留走势形状；
- 抽样只减少绘制点，不改变原始索引，缠论分型、笔、线段、中枢和买卖点仍按完整数据定位；
- 指标路径和布林带填充在超高密度数据下限制点数，降低 SVG/HTML 体积与浏览器布局压力；
- 缓存增量刷新不再复制完整 OHLCV 数据，Chan 标签增加跨类型像素矩形避让，减少密集行情下的文字重叠；
- 可视窗口裁剪、批量 SVG 图元、交易日历/会话适配和按缩放级别切换的聚合 K 线已接入；GPU 导出页继续复用缠论源索引，并在缩放时保持语义 Overlay 坐标一致。

当前闭环还包括：`KlineFrame`/revision 缓存失效、指标 lookback 预热、主图/副图语义面板、Chan 背驰候选独立图层、结构命中区域及统一 JSON 场景 schema。多周期结果默认叠加到主图，基础周期显示分型/买卖点，高周期默认显示结构线；设置 `show_multi_timeframe_annotations` 后可按需显示高周期标注。

### P2：指标与研究工作流（基础能力已落地）

1. 参考 stockstats 的命名和按需计算方式，已提供 `CompositeDefinition`/`compute_composite`/`computeComposite`，支持命名中间结果、显式参数和依赖图环检测。
2. 对同一数据帧的多个指标做依赖合并和缓存，已在 Rust 核心完成；`evaluate_cached` 通过数据版本和图结构签名实现跨请求复用。
3. 增加信号、事件、持仓三个独立层，缠论结果只负责提供结构事实，策略层自行定义交易规则。

## 验收指标

- 数值/结构：同一输入重复运行结果完全一致；结构索引单调；中枢上下沿始终满足 `lower <= upper`。
- 兼容性：默认关闭缠论叠加时现有 SVG、HTML、Python API 输出不变。
- 性能：批量分析不产生不必要的 Python 对象；增量刷新不重复累积 DrawList primitive。
- 可解释性：每个结构均能回溯到原始 K 线索引；未确认结构不能被标记为已确认。
- 可测试性：核心算法使用属性测试和真实 fixture；渲染层至少覆盖 SVG、HTML、JSON 三种输出。

## 已采用的默认规则与后续校准项

1. 默认笔口径为最小 6 根，另提供 5/7 根和阈值策略。
2. 默认严格分型，同时提供宽松和向右确认策略。
3. 默认支持递归层级中枢与多周期联立，候选信号仍需用真实市场 fixture 校准。
4. 买卖点和背驰属于核心结构候选输出，不直接等同于可执行交易指令。
5. SVG/HTML、Canvas、Node、Python 和 WASM 均作为统一场景的消费端；真实 wasm32 发布产物仍需目标工具链验收。
